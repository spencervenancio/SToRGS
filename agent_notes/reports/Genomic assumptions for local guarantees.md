# A known background makes local tests cheap

Nobody in the surveyed literature has used genomic domain assumptions to get a per-sequence error guarantee (FDR, type-I error, or coverage) for windows or motif instances picked out by a trained sequence model. The parts all exist separately: exact motif-scan p-values under a Markov background, Markov-chain knockoffs for genotypes, and instance-wise randomization tests on images and text. Of the four assumptions asked about, one does real work. A stated background DNA model (bases drawn i.i.d. or from a low-order Markov chain) gives an exact, cheap way to redraw a window given its flanks. That makes a per-window conditional randomization test (CRT: redraw the window many times, see whether the model's output on the real window is unusual) exact under that model. Grammar and sparsity structure, discreteness, and held-out sequences help much less. As a careful empirical study, the direction is realistic for an undergraduate thesis. It overreaches if it claims new theory or control over biologically functional sites. The searches were shallow (about 15 tool calls per note), so the claim that this has not been done is unverified.

## Exact background-model tests are old, but only for fixed scores

Motif scanners already compute exact p-values for a PWM (position weight matrix, a per-position table of base preferences) at one window. FIMO assumes a **zero-order background** and applies Benjamini–Hochberg on top ([FIMO docs](https://web.mit.edu/meme/current/share/doc/fimo.html)). motifcounter supports order-d Markov backgrounds but recommends **d = 1–2**, because higher orders start absorbing real motif signal ([motifcounter](https://bioconductor.posit.co/packages/3.19/bioc/vignettes/motifcounter/inst/doc/motifcounter.html)). Sesia, Sabatti and Candès built exact knockoffs for Markov chains and HMMs ([arXiv 1706.04677](https://arxiv.org/pdf/1706.04677)), but for SNP genotypes across many people, with FDR averaged over a dataset. KIMI tried Markov knockoffs for DNA motifs and gave up, because its features were derived k-mer counts that were "not exchangeable in distribution" ([KIMI](https://academic.oup.com/bioinformatics/article/37/6/759/5942973)). On the local side, Burns et al. defined instance-wise tests with BH, but only for ImageNet and text classifiers, with inpainting networks as counterfactuals ([arXiv 1904.00045](https://arxiv.org/pdf/1904.00045)). SHAP-XRT ([arXiv 2207.07038](https://arxiv.org/abs/2207.07038v4)) and x-SKIT ([arXiv 2405.19146](https://arxiv.org/pdf/2405.19146)) also define per-sample nulls, again outside genomics.

## Structure on the function buys interpretability, not inference

Grammar models do not come with per-sequence tests. SQUID fits additive or pairwise surrogates around a single sequence and reports point estimates, with no standard errors or selection rule ([SQUID](https://www.biorxiv.org/content/10.1101/2023.11.14.567120.full.pdf)). ExplaiNN writes the model as a sum of single-filter units, which makes "which unit matters here" well defined ([ExplaiNN](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC10303849/)). Thermodynamic models are **non-identifiable**: many parameter sets fit the data equally well ([PMC8686167](https://pmc.ncbi.nlm.nih.gov/articles/PMC8686167)). Discreteness lets SHAP zero compute Shapley values exactly, but only if the model is Fourier-sparse with interactions of order **five or less**, and it averages over uniform nucleotides; it reports no intervals ([SHAP zero](https://arxiv.org/html/2410.19236v4)). No paper proves that a motif-grammar assumption lets a procedure recover the true per-sequence support. One structural point does connect to the thesis. Billboard grammar (sites act roughly additively, so order and spacing matter little) makes the local value function close to monotone. Enhanceosome grammar (a precise arrangement is required) predicts exactly the non-monotonicity the thesis already flags ([Melnikov et al.](https://www.nature.com/articles/nbt.2137)).

## The background model is the assumption that helps

Under an order-k Markov law, a window's conditional distribution depends only on the k bases on each side, so exact redraws are cheap. Images, by contrast, needed a generative inpainter. The model stays fixed, so the test needs no refitting. With 10 tiles of 20 bp per sequence and BH at α = 0.1, about **200 draws per tile** are needed for any tile to reject at all. That is trivial for a small CNN (CNN: convolutional network scanning the sequence). Held-out sequences matter only in the ordinary sense that the tested sequence was not used for training.

## Three risks set the ceiling

First, the guarantee covers the model, not biology. It says "the CNN's output depends on this window beyond background redraws," not "this window is a functional site," and Burns et al. note that a naive conditional-independence null is false almost by construction for a fixed model ([arXiv 1904.00045](https://arxiv.org/pdf/1904.00045)). Second, real DNA is not low-order Markov. Repeats, CpG depletion, and Alu elements break it ([arXiv q-bio/0502009](https://arxiv.org/pdf/q-bio/0502009); [BMC Genomics](https://link.springer.com/article/10.1186/1471-2164-12-S2-S10)), and the field calibrates against reversed or shuffled genomes instead of trusting nominal p-values ([BaMM](https://academic.oup.com/nar/article/44/13/6055/2457621)). No study found measures how far type-I error inflates. Third, if the same Markov model generates the data, trains the CNN, and draws the replacements, FDR control holds almost by definition. Only a deliberate mismatch between these makes the result informative. Two smaller issues: overlapping tiles are positively dependent, which calls for Benjamini–Yekutieli, and motifs that straddle tile boundaries split their signal. Several supporting details are from memory and unverified: Huang–Janson conditional knockoffs, which allow estimated Markov parameters; KnockoffZoom's region-level scope; and DFIM's lack of any null.

## Conclusion

The domain does not make guarantees easier through grammar or discreteness. It makes them easier because a background model replaces the hardest part of a local test, the counterfactual sampler, with something exact and cheap. The thesis contribution is therefore empirical, not theoretical: a per-window CRT with within-sequence BH/BY, validated on planted motifs, with a mismatch axis showing when FDR breaks and a comparison against thresholded saliency. That last comparison feeds directly into the thesis's open threshold-calibration problem. Expect the main risk to show up at review as the objection "BH works when the null is true by construction." Pre-registering the mismatch experiment is the answer to it.
